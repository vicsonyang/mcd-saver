# 配置指南

本 Skill 依赖三项能力。配置齐全时直接使用，不重复讲解；缺失时只展示缺失项的补齐步骤。

## 一、mcd-mcp（必需）

麦当劳点餐接口由该连接器提供，支撑自动领券、查询可用券、生成候选方案、最优组合试算、创建订单、定时推送与积分提醒。

**凭据边界**：麦当劳会员授权由连接器侧承载。本 Skill 不接触任何密码、令牌或 Cookie，不要求你在对话中粘贴凭据，也不保存任何凭据。

**配置步骤**：

1. 打开 WorkBuddy 的自定义连接器管理入口（聊天窗口左下角的连接器管理页）
2. 在自定义连接器区域找到该连接器，点击信任以启用
3. 按连接器自身的引导完成麦当劳账号登录与授权
4. 完成后回到对话，重新发起点餐请求

**最小验证**：调用一次 `now-time-info`。能返回服务器时间即视为可用。这一步是只读的，不领券、不下单、不消耗积分。

**说明**：该连接器的官方主页与文档地址未从官方渠道核验，本指南不臆造网址。需要了解来源时，在连接器管理页查看该连接器的详情。WorkBuddy 自身的说明见 https://www.workbuddy.cn/docs/workbuddy/Overview

**撤销**：在连接器管理页移除或取消信任该连接器，即断开授权。移除后本 Skill 会停止，不会降级为猜测数据。

**状态判断**：

| 现象 | 状态 | 处理 |
|---|---|---|
| 能返回服务器时间 | 可用 | 直接进入流程 |
| 连接器未注册或未信任 | 待配置 | 只展示上述补齐步骤 |
| 已注册但调用报错 | 不可用 | 区分登录失效、权限不足与额度问题，给出恢复步骤 |
| 网络超时 | 不可用 | 重试两次后停止，说明当前无法获取真实价格 |

## 二、python-runtime（可选）

环境检查脚本需要 Python 3.10 及以上，只使用标准库，不安装任何第三方包。

不可用时改为人工逐项确认清单：连接器是否已信任、能否返回服务器时间、门店与地址是否可取到。检查结论标注为未验证。

## 三、workbuddy-automation（可选）

定时推送依赖宿主的自动化能力。宿主支持时在创建自动化任务时填入推送时间与指令；不支持时改为用户手动发起，不谎称已配置定时推送。

## 四、环境检查脚本

先完成最小只读探测，再运行脚本：

```
python scripts/check_environment.py --capability 最优组合试算 --probe-results <临时目录>/probe-results.json
```

**探测结果文件不能省略。** 检查脚本不会自己去调接口，缺少它时会把实际可用的状态判为不可用。

文件按依赖编号与检查编号两级组织，只记录状态，不含任何凭据或业务数据。

**照抄下面这份即可，不要自己简化结构**（实测最常见的返工原因：把键名写成 `now-time-info`，或把 `check_type`/`target` 挪到顶层，脚本会判为 `configuration_invalid`，白跑一轮）：

```json
{
  "mcd-mcp": {
    "mcd-mcp-time-probe": {
      "check_type": "mcp_probe",
      "target": "now-time-info",
      "status": "ready",
      "reason_code": "ok",
      "checked_at": "2026-10-13T03:59:50Z"
    }
  }
}
```

三个字段的取值固定，写错任一个都会判为不可用：

```
外层键名        "mcd-mcp"               依赖编号，必须与 skill-dependencies.json 一致
内层键名        "mcd-mcp-time-probe"    检查编号，必须与清单里该项的 id 一致
check_type      "mcp_probe"             必须与清单里该项的 type 一致
target          "now-time-info"         必须与清单里该项的 target 一致
status/reason   "ready" / "ok"          探测成功就固定这两个值
checked_at      ISO 8601，UTC，秒级，以 Z 结尾   例：2026-10-13T03:59:50Z
```

`checked_at` 取当前 UTC 时间即可，用 `date -u +%Y-%m-%dT%H:%M:%SZ` 生成，不要自己推算时区。缺 Z 结尾、或写成带 `+08:00` 的本地时间，都会被判为不匹配。

**一次探测、一次检查就够。** 探测只需 `now-time-info` 这一个只读调用；脚本本身不调接口、不读写配置，纯读本地文件，运行很快。若脚本返回 `unavailable` 且 `reason_code` 是 `probe_required` 或 `configuration_invalid`，问题几乎一定出在上面这份 JSON 的键名或字段上，改它，不要反复重跑脚本，也不要转而怀疑连接器不可用。

只读检查，不修改配置、不登录、不安装、不授权。输出四种状态：

```
ready        直接进入流程，不展示教程
partial      继续可用功能，说明受影响范围与降级方式
needs_setup  只展示缺失必需项的补齐步骤，完成后重检
unavailable  展示故障原因、恢复步骤与安全降级
```

## 五、降级原则

任何一项能力不可用时，只关闭受影响的功能，不笼统宣布整个 Skill 不可用。

核心价格数据、权限或安全条件缺失时停止受影响流程，不用猜测数据顶替。拿不到真实价格就直说算不出，不输出估算价格冒充实付。
